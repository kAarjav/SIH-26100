# Koshagar

A responsive interactive showcase for Team Shaurya's SIH 2026 proposal, **AI-Driven Standardization and Harmonization of Material Codes Across CPSEs** (PS SIH26099).

## Run locally

No installation is required. From this folder, run:

```bash
npm start
```

Then open <http://localhost:5173>.

## Included

- Responsive product landing page with smooth scroll and reveal animations
- Animated material-harmonization hero visual
- Interactive fixed-data concept demo with analysis and approval states
- Six-stage material master pipeline
- CPSE platform architecture visualization
- Mobile navigation and reduced-motion support

The harmonization experience is a front-end concept demonstration. It uses fixed sample records and does not claim to connect to a live AI model, database, SAP system, or ERP.# SIH-26100
